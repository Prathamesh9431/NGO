# NGO Website

A modern and responsive NGO website built using **React.js**. The project is designed to create an engaging online presence for an NGO, allowing visitors to learn about its mission, initiatives, and ways to contribute.

## 🚀 Features

* Responsive design for desktop and mobile
* Modern and clean user interface
* React component-based architecture
* Easy navigation
* Fast and optimized performance

## 🛠️ Tech Stack

* React.js
* JavaScript
* HTML5
* CSS3
* Vite

## 📂 Project Structure

```
src/
 ├── assets/
 ├── components/
 ├── pages/
 ├── App.jsx
 └── main.jsx
```

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Prathamesh9431/NGO.git
```

Navigate to the project folder:

```bash
cd NGO
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
